Mis Favoritos es un sitio web interactivo y responsivo desarrollado como proyecto final para la materia de Programación para Internet. 
En este espacio comparto recomendaciones de películas, series y libros, demostrando la integración de un diseño estructurado en HTML5 y CSS3 con interactividad avanzada mediante JavaScript y jQuery. 
El proyecto destaca por mantener una arquitectura limpia que separa la lógica visual de la funcional, e incluye características dinámicas como un Modo Oscuro, animaciones de fondo, un mapa interactivo de Google Maps, 
validación de formularios en tiempo real, manipulación directa del DOM y la implementación del plugin externo bxSlider para enriquecer la experiencia del usuario.
